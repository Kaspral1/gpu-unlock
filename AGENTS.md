## Reporting results

- For **Turing (RTX 20)** compatibility reports (working unlocks with benchmark output), use the `Turing / RTX 20 Compatibility Report` template in this repository (`Kaspral1/gpu-unlock`).
- For failures, no speedup, or lost unlocks, open an issue using `.github/ISSUE_TEMPLATE/unlock-failure.yml` and fill in every required field. Search existing issues first before opening a new one.
- For upstream Ampere/Ada-only reports, see `https://github.com/Zagitta/gpu-unlock/discussions/238`.
